# Documentación del proyecto

Esta carpeta contiene guías, bitácoras y resúmenes de cambios.

## Qué sí es
- Referencia para desarrollo y soporte.
- Historial de implementaciones por tema.

## Qué no es
- No forma parte del build del frontend.
- No afecta runtime de backend o frontend.

## Organización sugerida
- `api/`: endpoints y contratos.
- `pagos/`, `perfil/`, `promocion/`, `import-users/`: guías por módulo.
- `deploy-infra/`: despliegue, CORS, caché.
- `general/`: instrucciones globales.
- `conceptos/`: documentación funcional del módulo de conceptos.
